# HU-PAC-003: Agendamiento de citas por el paciente

## Historia de Usuario
Como paciente, quiero agendar una cita con un doctor seleccionando fecha y hora disponible, para asegurar mi atención médica.

## Rol
Paciente

## Prioridad
Alta

## Criterios de Aceptación
- El sistema debe mostrar un calendario con los próximos 30 días.
- El sistema debe mostrar solo los días y horas disponibles del doctor.
- El sistema debe permitir seleccionar tipo de cita: presencial o virtual.
- El sistema debe mostrar un resumen de la cita antes de confirmar.
- El sistema debe guardar la cita y mostrar un mensaje de confirmación.
- El sistema debe agregar la cita al historial del paciente.
- El sistema debe notificar que la cita fue agendada correctamente.

## Interfaz esperada
- Selector de tipo de cita (presencial/virtual).
- Calendario mensual con días disponibles resaltados.
- Slots horarios disponibles al seleccionar un día.
- Resumen de la cita: doctor, especialidad, fecha, hora, tipo.
- Botón "Confirmar cita".
- Pantalla de confirmación con mensaje de éxito.

## Colores
- Días disponibles: #3498DB
- Slots disponibles: #D5F5E3 / #27AE60
- Botón confirmar: #3498DB
- Fondo: #F5F7FA
- Texto: #1A1A1A
