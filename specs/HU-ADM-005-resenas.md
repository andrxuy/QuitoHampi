# HU-ADM-005: Gestión de reseñas

## Historia de Usuario
Como administrador, quiero gestionar las reseñas y calificaciones de los médicos realizadas por los pacientes (visualizar, ocultar solo contenido ofensivo o falso, y eliminar spam), para que el sistema refleje experiencias reales y útiles sin contenido que distorsione la reputación profesional.

## Rol
Administrador

## Prioridad
Media

## Riesgo
Media

## Desarrollador responsable
Andrés Gustavo Oto Caza

## Criterios de Aceptación
- El sistema debe permitir al administrador visualizar todas las reseñas y calificaciones.
- El sistema debe buscar palabras clave para identificar reseñas ofensivas o spam.
- El sistema debe permitir al administrador eliminar las reseñas con contenido ofensivo o falso.
- El sistema debe permitir al administrador ocultar reseñas sin eliminarlas permanentemente.
- El sistema debe dar al administrador control total sobre las reseñas publicadas.

## Observación
El administrador debe tener control sobre las reseñas.

## Interfaz esperada
- Página con sidebar de administrador.
- Grid de tarjetas de reseñas (2 columnas).
- Cada tarjeta muestra: avatar del paciente, nombre, médico calificado, estrellas, comentario, fecha.
- Filtros: input de búsqueda por palabra clave, select de estado (Todas/Visibles/Ocultas).
- Botones: Ocultar/Mostrar, Eliminar.
- Las reseñas ocultas se muestran con opacidad reducida.
- Modal de confirmación para ocultar y eliminar.
- Las palabras clave buscadas se resaltan en amarillo dentro del texto.
