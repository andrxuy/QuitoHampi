# HU-ADM-003: Visualización de un tablero

## Historia de Usuario
Como administrador, quiero visualizar un tablero con información general (médicos registrados, pacientes, citas agendadas, videoconsultas realizadas), para tener una visión más rápida y eficaz del sistema.

## Rol
Administrador

## Prioridad
Alta

## Riesgo
Bajo

## Desarrollador responsable
Andrés Gustavo Oto Caza

## Criterios de Aceptación
- El sistema debe mostrar un tablero con médicos registrados, pacientes, citas agendadas y videoconsultas realizadas.
- El sistema debe tener filtros para buscar por apellido, especialidad, edad y reseñas.
- El sistema debe mostrar la información registrada de cada médico.
- El sistema debe mostrar la foto del profesional en la tabla.
- El sistema debe organizar correctamente la tabla de médicos para el administrador.

## Observación
Debe el administrador tener bien organizada la tabla de médicos.

## Interfaz esperada
- Sidebar de 280px con menú de navegación.
- 4 tarjetas de resumen con iconos y valores numéricos.
- Tabla de médicos con columnas: Foto, Nombre, Especialidad, Estado, Acciones.
- Filtros: input de búsqueda por apellido, select de especialidad, select de estado.
- Badges de estado: Verificado, Pendiente, Rechazado.
- Botones de acción: Ver, Editar, Eliminar.
